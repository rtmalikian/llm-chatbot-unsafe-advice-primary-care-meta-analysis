# Screening rules, Set A (inclusion-first checklist), v1, 2026-11-12

Screener A reads title and abstract. Work down the list. A record PASSES (include or maybe) unless a hard exclusion is certain from the title and abstract alone.
Pass if all of these could hold:
A1. A general-purpose LLM chatbot (ChatGPT, GPT, Claude, Gemini, Llama, Copilot, Bard, or a named general model) was tested.
A2. The questions or users are patient-facing: patient-posed questions, patient scenarios, or laypeople using the system for their own health questions.
A3. The topics could present in primary care (symptoms, common conditions, general medication questions, prevention, disposition).
A4. Safety, harm, accuracy with a harm tier, or disposition was rated by clinicians or a clinical rubric.
Hard exclusions (exclude only if certain):
AX1. Clinician-facing use only (documentation, summarisation, diagnosis support for clinicians, exam performance with no patient-facing arm).
AX2. No LLM (rule-based symptom checker only, search engine only, older chatbot with no LLM).
AX3. Review, editorial, protocol, framework, or opinion with no primary rated responses.
AX4. Mental-health crisis or self-harm only.
AX5. Clearly specialty-only content that would not present in primary care.
Decisions: INCLUDE (clearly passes), MAYBE (could pass, full text needed), EXCLUDE (hard exclusion, give the AX code). When torn between MAYBE and EXCLUDE, choose MAYBE. Record one reason code per record.
